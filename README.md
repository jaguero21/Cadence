# Cadence

A private, on-device iOS app for daily symptom, mood, energy and sleep
tracking. It runs weekly reviews, finds patterns in your own logs, imports
from Apple Health, and exports doctor-ready reports.

Website: <https://jaguero21.github.io/Cadence/>

## Building

Requires Xcode 27 (Swift 6 language mode, iOS 27 SDK). Open
`Cadence.xcodeproj`, select the `Cadence` scheme, and build. Run the tests
with ⌘U. Project conventions and architecture notes live in `CLAUDE.md`.
